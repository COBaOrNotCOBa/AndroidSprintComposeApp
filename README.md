# AndroidSprintComposeApp

Небольшое вводное приложение на Jetpack Compose. Проект сделан в рамках спринта по Android, чтобы попробовать декларативный UI, навигацию и базовую архитектуру на современном стеке.

## Что демонстрирует проект

- Построение интерфейса на **Jetpack Compose**
- Использование **Material 3** компонентов
- Навигация между экранами через **Navigation Compose**
- Работа с жизненным циклом через **androidx.lifecycle**

## Стек и требования

- **Язык:** Kotlin
- **UI:** Jetpack Compose + Material 3
- **Навигация:** androidx.navigation.compose
- **Минимальная версия Android:** 8.0 (API 26)
- **Target / compile SDK:** 36
- **Java / Kotlin:**
  - Java 17
  - Kotlin с `jvmTarget` 17

Рекомендуется последняя версия **Android Studio** с поддержкой Compose.
