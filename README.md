# AndroidSprintComposeApp

Небольшое вводное приложение на Jetpack Compose. Здесь я пробовал декларативный подход к UI на Android: разметку в виде функций, состояние и реактивные обновления интерфейса.

## Что демонстрирует проект

- Базовую работу с Jetpack Compose
- Построение UI без XML
- Простую навигацию/экраны (в зависимости от реализации)

## Технологии

- Kotlin
- Jetpack Compose
- Android SDK

## Как запустить

1. Открыть проект в Android Studio с поддержкой Compose.
2. Запустить приложение на эмуляторе или устройстве.

## Статус проекта

Учебный пример для знакомства с Compose. Может служить стартовой точкой для более сложных приложений.
